# Roadmap

수동 QA 체크리스트와 개선 후보. 구현 완료 기능은 [README](../README.md), 화면 동작은 [ux.md](./ux.md), 빌드 실패 조건은 [architecture.md §3](./architecture.md), 진행 기록은 [WORK.md](../WORK.md)를 본다.

## 1. 수동 QA 체크리스트

자동 검증(빌드·테스트)이 다루지 않는 항목만 적는다.

- 배포 후 커스텀 도메인(`https://passture.logonme.click/`)에서 `data/catalog.json`, 문제 JSON, 이미지 등 모든 자원 경로가 정상 응답한다.
- 새 출처를 입력한 뒤에는 [review-checklist.md](./review-checklist.md) 기준으로 원본 대조·풀이 가능성·정답 누출·해설을 검토한다.

## 2. 개선 후보

### 2.1 다음

- 모의 시험 UX: ID 그룹 기반 균등 추출 설명과 예외 안내 보강
- 연도/ID 그룹/강의 단위 필터
- 세션 복구 UX (현재는 같은 조건이면 `sessionStorage` 세션을 자동 재사용)
- 이미지 빌드 시 경고/에러 분리
- 모바일 반응형과 접근성 점검 보강

### 2.2 이후

- 태그 검색·태그 필터 (문제 본문·선택지·해설·ID 검색은 선택 화면 `문제 검색`에 이미 있음)
- 시드 기반 세트 공유 URL
- 추가 정오표/정답표 발견 시 정답 대조
- 마크다운/코드 하이라이트 렌더링
- 다크 모드 도입 여부
- 문제 작성 보조 도구 (별도 페이지, 브라우저 내 YAML 입력 폼 → 다운로드)
- 이미지 빌드 최적화 (WebP)
- 학습 통계 깊이 (태그별 정답률, 주차별 추세)
