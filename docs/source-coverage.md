# 2학기 출처 현황

2학기 과목마다 기출·강의·교재(기본서)·워크북 문제가 있는지, 데이터에 들어갔는지 추적한다. 1학기 과목은 추적하지 않는다.

## 상태 값

| 상태      | 의미                                                        |
| --------- | ----------------------------------------------------------- |
| 입력 완료 | `data/`에 입력하고 카탈로그에 등록했다                      |
| 입력 중   | 원본을 확보해 입력·검증을 진행하고 있다                     |
| 없음      | 해당 과목에 이 종류의 문제 자료가 없다고 확인했다           |
| 원본 확보 | 원본은 확보했지만 아직 입력하지 않았다                      |
| 확인 필요 | 자료가 있는지 아직 확인하지 않았다(따로 답이 없으면 기본값) |

## 현황

| 과목             | 기출                                           | 강의                       | 교재                       | 워크북                       |
| ---------------- | ---------------------------------------------- | -------------------------- | -------------------------- | ---------------------------- |
| 선형대수         | 입력 완료 (2017~2019)                          | 입력 완료 (1~15강, 30문제) | 없음                       | 없음                         |
| 컴퓨터과학개론   | 입력 완료 (2017~2019)                          | 입력 완료 (1~15강, 65문제) | 입력 완료 (1~8장, 104문제) | 입력 완료 (1~8장, 162문제)   |
| 컴퓨터구조       | 입력 완료 (2017~2019)                          | 확인 필요                  | 확인 필요                  | 확인 필요                    |
| 프로그래밍언어론 | 입력 완료 (기말 2017~2019, 출석대체 2017~2018) | 없음                       | 없음                       | 원본 확보 (입력 예정)        |
| 컴파일러구성     | 입력 완료 (2017~2019)                          | 입력 완료 (1~15강, 84문제) | 확인 필요                  | 입력 완료 (1~8장, 315문제)   |
| 시뮬레이션       | 입력 완료 (2017~2019)                          | 입력 완료 (1~15강, 75문제) | 확인 필요                  | 확인 필요                    |
| C프로그래밍      | 입력 완료 (2017~2019)                          | 확인 필요                  | 없음                       | 입력 완료 (연습문제 107문제) |
| UNIX시스템       | 입력 완료 (2017~2019)                          | 확인 필요                  | 확인 필요                  | 확인 필요                    |

## 갱신 규칙

- 사용자가 자료 유무를 알려주면 해당 칸을 `있음`이 아니라 실제 진행 상태(`입력 중`, `입력 완료`, `없음`)로 바꾼다. 원본은 확보했지만 아직 입력하지 않았으면 `원본 확보`로 적는다.
- 새 출처를 입력하고 카탈로그에 등록하면 같은 작업에서 이 표를 `입력 완료`로 갱신한다.
- 2학기 과목을 새로 추가하면 행을 추가하고, 알려진 것이 없으면 모든 칸을 `확인 필요`로 둔다.
