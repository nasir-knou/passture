# 출처 현황

카탈로그 과목과 2학기 과목별 기출·강의·교재(기본서)·워크북 문제 입력 상태를 추적한다.

- 1학기 5과목: 운영체제, 이산수학, 알고리즘, 인공지능, Java프로그래밍. 출처 현황은 추적하지 않고, 챕터별 풀이는 보류한다.
- 2학기 8과목: 아래 표. 컴퓨터구조는 수강하지 않아 기출만 유지하고 나머지는 대상 제외다.
- 챕터별 풀이 대상은 2학기 7과목(선형대수, 컴퓨터과학개론, 프로그래밍언어론, 컴파일러구성, 시뮬레이션, C프로그래밍, UNIX시스템)이다.

## 상태 값

| 상태      | 의미                                                        |
| --------- | ----------------------------------------------------------- |
| 입력 완료 | `data/`에 입력하고 카탈로그에 등록했다                      |
| 원본 확보 | 원본은 확보했지만 아직 입력하지 않았다                      |
| 없음      | 해당 과목에 이 종류의 문제 자료가 없다고 확인했다           |
| 확인 필요 | 자료가 있는지 아직 확인하지 않았다(따로 답이 없으면 기본값) |
| 대상 제외 | 수강하지 않는 과목이라 자료를 찾거나 입력하지 않는다        |

## 갱신 규칙

- 사용자가 자료 유무를 알려주면 `있음`이 아니라 실제 상태(`입력 완료`, `원본 확보`, `없음`)로 적는다.
- 새 출처를 입력하고 카탈로그에 등록하면 같은 작업에서 해당 칸을 `입력 완료`로 갱신한다.
- `챕터별 풀이`는 syllabus 등록·장 배정 여부다(`지원`, `미지원`, `대상 제외`).
- 2학기 과목을 새로 추가하면 행을 추가하고, 알려진 것이 없으면 모든 칸을 `확인 필요`로 둔다.
