# UX

현재 구현된 주요 화면, 랜덤화 정책, 저장소 사용, 데이터 관리 흐름.

## 1. 주요 화면

### 1.1 홈

- 상단바: 문제 선택, 모의 시험, 학습 기록, 데이터 관리
- 학기 필터 `전체 / 1학기 / 2학기`. 기본값은 항상 `전체`다(여러 과목의 자료를 먼저 보여주기 위해 날짜 기준 기본값을 쓰지 않는다).
- 과목 카드: 학기 배지, 출처 수, 출처 목록(`2019 기말 · 기출`), 선택 버튼(`#/select?subject={subjectId}`로 진입)

### 1.2 과목/문제 선택

- 학기 필터 `전체 / 1학기 / 2학기`, 과목 select(`1학기 · 운영체제`처럼 표시, 선택한 학기의 과목만)로 화면 안에서 과목을 바꾼다. 학기는 URL `semester`(`all / 1 / 2`)로 유지한다.
- 기본 학기: 홈 과목 카드로 들어오면 그 과목의 학기. 과목 없이 들어오면(상단바 등) 기기 로컬 시간 기준 2월~7월 1학기, 8월~1월 2학기이고 그 학기에서 출처가 있는 첫 과목을 고른다. 학기 필터를 바꿀 때도 첫 과목으로 이동한다.
- 과목 select 옆에 학습 상태(북마크 수, 오답 문항 수, 오답 누적 횟수, `오답 보기` → `#/history?filter=wrong&subject={subjectId}`, 없으면 `풀이 기록 없음`)를 보인다.
- 출처 체크리스트(다중 선택, 기본 선택 없음): 분류 `기출 / 교재(기본서·워크북) / 강의(연습문제·특강)` 배지, 기출은 최신 연도순 먼저·나머지는 등록 순, 이름 옆에 `(25문제)` 형식 문제 수. `문제 검색`은 출처명·분류·연도와 문제 본문·선택지·해설·ID로 출처 목록을 거른다.
- 문제 범위 `전체 / 북마크만 / 오답만`, 문제 순서·선지 순서 `기본 / 순서 무작위`
- 선택 요약(출처 수, 총 문항 수, 출처 칩)과 풀이 시작 버튼

### 1.2.1 챕터별 풀이

- `catalog.yaml`에 `syllabus`가 있는 과목(대상: [source-coverage.md](./source-coverage.md))만 `출처별 / 챕터별` 전환이 나타나고, 나머지는 출처별 풀이만 제공한다. URL은 `#/select?subject={subjectId}&semester={학기}&mode=chapter`.
- 챕터별 모드는 출처 체크리스트 대신 교재 장 목록을 보여준다. 교재에 부 구분이 있으면(선형대수 Ⅰ–Ⅲ부) 부 단위로 묶고 `부 전체` 버튼을 제공한다. `전체 선택 / 전체 해제` 버튼도 있다.
- 장마다 `강의 N · 교재 N · 기출 N` 문제 수와, 그 장을 다루는 강 번호(`3–4강`)를 표시한다. 어떤 종류에도 문제가 없는 장은 비활성화한다.
- 문제 종류는 `강의 / 교재 / 기출` 체크박스로 고른다. 과목에 해당 종류의 출처가 없으면 `(준비 중)`으로 비활성화한다.
- 문제 범위(전체/북마크만/오답만)와 문제·선지 순서 옵션은 출처별 모드와 같다.
- 문제 순서 `기본`은 장 순서 → 강의 → 교재 → 기출 → 출처 등록 순서 → 파일 내 문제 순서다.
- 교재 개정으로 현재 목차에 없는 기출(`outdated: true`)은 챕터별 풀이에서 제외하고, 제외된 문제 수를 안내한다. 연도별 풀이와 모의 시험에는 그대로 나온다.
- 풀이 화면과 결과 문제 카드의 출처 라벨에 `선형대수 - 2019 기말 · 4장`처럼 장을 함께 표시한다. 결과 화면에는 `장별 결과`(장별 정답률)를 추가로 보여준다.
- 결과 화면의 `오답만 / 북마크만 다시 풀기`는 챕터별 풀이에서 선택한 장·문제 종류를 유지한 채 범위만 바꾼다.
- 북마크·오답 기록은 출처별 풀이와 같은 문제 키를 쓰므로 두 모드에서 공유된다.

### 1.3 문제 풀이

- 상단바: 문제 선택, 모의 시험, 풀이, 결과, 데이터 관리 (결과 화면도 같다)
- 상단: 출처 라벨, 현재 문제/전체 문제 표시, 답안 체크 기준 진행률과 정답 확인 수, 문제·선지 순서 옵션 상태
- 문제 번호 지도: 현재 문제, 답안 체크 여부, 정답 확인 여부, 북마크를 표시하고 번호 클릭으로 이동한다. 기본은 현재 문제 주변 한 줄(26개)만, `전체 보기 / 접기`로 전체 번호와 범례를 펼친다.
- 공통 지문(식별자는 숨김) → 문제 본문 → 첨부 이미지 → 선택지(복수 정답은 체크박스, 나머지는 라디오) 순으로 표시한다.
- 문제 위 `이전 / 북마크 / 다음`, 문제 아래 `이전 / 정답 확인 / 다음` 버튼. 확인한 문제는 `다시 확인`으로 다시 채점할 수 있다.
- 정답 확인 후 선택지 색상으로 정답·오답을 표시하고, 해설 영역에 문제 키, 정답 번호(표시 순서 기준), 해설을 보인다.
  - 해설의 `선택지 N:` 줄은 보기별로 `N번 (정답/오답)`과 함께, `핵심 개념` 블록은 따로 묶어 표시한다. `※`로 시작하는 줄은 해설 끝 별도 안내 블록에 한 줄씩 표시한다. 인라인 코드와 강조 표기는 [data-schema.md](./data-schema.md) 참고.
- 모든 문제에 답안을 체크하면 하단 `채점하기` 버튼 활성화. 채점하기는 정답 확인을 하지 않은 답안도 함께 채점하고 결과 화면으로 이동한다.
- 하단에 모든 문제에 1번 보기를 체크하는 `모든 답안 1번 체크` 버튼이 있다.

### 1.4 결과

- 총 문항, 응답, 정답, 정답률 카드
- 리포트: 정답률 막대와 정답 / 오답 / 미응답 수
- 출처별 결과(출처별 정답률), 챕터별 풀이면 장별 결과
- 문제별 정답 / 오답 / 미응답 지도
- 번호 클릭 시 해당 문제, 선택지, 정답/오답, 해설 표시 (`#/result?question={번호}`)
- 풀이로 돌아가기 / 오답만 다시 풀기 / 북마크만 다시 풀기 / 새 세션 시작
  - 다시 풀기는 이번 세션의 출처를 그대로 쓰고 범위만 `오답만`(`pt.wrongAnswers` 기준) 또는 `북마크만`으로 바꿔 새 세션을 만든다.

### 1.5 학습 기록

- `#/history`(과거 `#/bookmarks`는 여기로 이동). 북마크와 오답 문제를 모아 전체·북마크·오답 수를 요약한다. 모든 문제 파일을 불러온 경우에만, 카탈로그에 더는 없는 문제의 북마크·오답 기록을 지운다(일부 파일을 못 불러오면 지우지 않는다).
- 필터: 기록 유형(전체/북마크/오답), 학기(기본 `전체`), 과목(선택한 학기의 과목만), 출처. URL의 `filter`, `semester`, `subject`, `source`로 유지한다.
- 모두 펼치기 / 모두 접기
- 문제 카드는 기본 접힘 상태:
  - 접힘: 문제 키, 과목/출처/분류, 북마크 배지와 `오답 N회` 배지, 문제 본문
  - 펼침: 지문, 선택지(정답 표시 없음), 북마크한 문제면 북마크 해제 버튼

### 1.6 데이터 관리

데이터는 로컬 브라우저에만 있고 자동 동기화되지 않으므로, 다른 기기로 옮길 때는 JSON 파일로 내보내고 가져온다(§4~§6).

- 가져오기는 파일을 고른 뒤 `병합` 또는 `덮어쓰기` 버튼으로 방식을 직접 고른다(충돌 검사 없음). 잘못된 JSON, 버전 불일치, 필수 필드 누락은 오류 메시지로 알린다.
- 현재 풀이 초기화: `sessionStorage`의 출처 선택, 챕터 선택, 범위/순서 옵션, 현재 풀이 세션 삭제
- 학습 기록 초기화: `localStorage`의 북마크와 오답 기록 삭제. 현재 풀이 초기화 항목도 함께 삭제
- 두 초기화 모두 확인 대화상자를 거친다. 모의 시험 설정·세션은 지우지 않는다.

### 1.7 모의 시험

- `#/mock-exam`(설정) → `#/mock-exam/test`(시험) → `#/mock-exam/result`(결과). 빌드된 문제 풀로 기말 시험 환경을 타이머와 함께 재현한다.
- 학기 필터의 기본값은 기기 로컬 시간 기준(2월~7월 1학기, 8월~1월 2학기)이다.
- 과목 1~3개, 시험 시간은 과목 수 × 25분(`전체 풀기`여도 같다). 과목마다 출처 하나만 고른다(기본 선택 없음, 기출 최신 연도순 먼저).
- 과목별 문항 구성 `무작위 25문제`(기본) / `전체 풀기`, 문제·선지 순서 `기본`(기본값) / `순서 무작위`. 추출 규칙은 [data-schema.md §4.1](./data-schema.md).
- 설정 화면에 과목 수, 시험 시간, 예상 시작·종료 시각, 과목별 문항 구성 요약을 보인다.
- 풀이 중에는 시험 시간(시작~종료 시각), 남은 시간(5분 이하 경고), 과목 탭(과목별 응답 수), 답안표, 책갈피를 보여준다.
  - 시험 시각은 시험 화면에 들어가 세션을 만든 시점부터 계산한다. 진행 중 세션은 `sessionStorage`에 남아 새로고침해도 이어지고, 남은 시간은 시작 시각 기준으로 계속 줄어든다.
  - 답안표는 문항마다 고른 보기를 화면 표시 순서 번호(①~)로 보여주고, 행을 누르면 해당 문항으로 이동한다.
  - 책갈피는 시험 안에서만 쓰는 표시로, 학습 기록의 북마크(`pt.bookmarks`)에는 저장하지 않는다.
  - 글자 크게 / 글자 작게, 세로 스크롤 ↔ 한 문제씩 보기 전환을 제공한다. 한 문제씩 보기에서는 이전/다음 버튼과 `현재 번호 / 전체` 표시가 나오고, 과목 탭을 바꾸면 그 과목의 1번부터 한 문제씩 보여준다.
- `시험실 퇴실` 확인 모달 또는 시간 종료 시 시험을 종료하고 `#/mock-exam/result`로 이동한다. 풀이 중 다른 라우트로 이동하면 확인 후 시험을 종료하고, 새로고침·탭 닫기에는 브라우저 이탈 경고를 띄운다.
- 결과 화면에는 시험형 결과 리포트를 표시한다.
  - 전체 총 문항, 정답, 전체 정답률
  - 과목 탭별 총 문항, 응답, 정답, 정답률 카드와 문제별 정답 / 오답 / 미응답 지도, 문제·선택지·정답·해설
  - 채점은 `choice.id` 기준이며, 모의 시험 결과는 오답 기록(`pt.wrongAnswers`)에 반영하지 않는다.
  - `새 모의 시험` / `세션 초기화`

### 1.8 스크롤 정책

- 라우트 이동 시 기본적으로 브라우저 스크롤 위치를 유지한다.
- 문제 선택 화면(`/select`)에 새로 진입할 때만 페이지 최상단으로 이동한다.

## 2. 랜덤화 정책

- 문제 순서: 사용자가 `순서 무작위`를 선택하면 풀이 세션 생성 시 Fisher-Yates 셔플로 섞는다. 기본값은 데이터 순서다.
- 선택지 순서: 사용자가 `순서 무작위`를 선택하면 세션 생성 시 섞는다. 기본값은 데이터 순서다. 정답 판정은 표시 순서가 아니라 `choice.id` 기준으로 한다. 화면의 보기 번호, 해설의 정답 번호·`N번 (정답/오답)`, 모의 시험 답안표 번호는 모두 표시 순서 기준이다.
- 모의 시험도 같은 문제·선지 순서 옵션을 따로 가진다. 기본값은 추출된 원래 순서를 유지하고, `무작위 25문제` 추출 자체는 순서 옵션과 관계없이 항상 무작위다.
- 시드: 아직 지원하지 않는다.
- 같은 세션 내에서는 순서를 유지한다. 세션은 `sessionStorage`에 저장되며, 출처·범위·순서 옵션이 같고 각 문제 파일 내용의 해시가 같으면(챕터별 풀이는 선택한 장·문제 종류와 강 → 장 대응까지 같으면) 새로고침 후에도 이어진다. 데이터 파일을 조금이라도 고치면 해시가 바뀌어 새 세션이 시작된다.
- 저장 형식: 풀이·모의 시험 세션은 version 2로, 문제 본문 없이 문제 키(출처 + 문제 ID)와 원본과 다른 선지 순서만 저장하고 답안·진행 상태를 함께 둔다. 풀이 결과·모의 시험 화면은 불러올 때 문제 파일을 비동기로 읽어 문제를 복원하며, 사라진 문제는 건너뛰고 하나도 남지 않으면 세션을 지운다. 이전 형식이거나 손상된 세션은 버리고 새로 시작한다. 문제 파일 fetch가 실패하면 세션은 그대로 두고 오류를 보인 뒤 다음 시도에서 다시 불러온다.
- 저장소 쓰기가 실패하면(용량 초과, 사생활 보호 모드 등) 한국어 토스트로 알린다(`src/lib/safe-storage.ts`, `app.ts`).

## 3. localStorage·sessionStorage 저장 항목

영구 사용자 데이터는 `localStorage`, 현재 풀이 세션과 선택 옵션, 풀이 화면 UI 상태는 `sessionStorage`에 저장한다.

```text
localStorage:
pt.bookmarks       # string[] (복합 키 배열)
pt.wrongAnswers    # Record<복합키, { wrongCount, lastWrongAt }>

sessionStorage:
pt.selectedSources # 현재 선택한 출처 배열
pt.chapterSelection # 챕터별 풀이 선택 { subjectId, chapters, categories }. 있으면 챕터별 세션으로 풀이한다
pt.practiceScope   # all | bookmarked | wrong
pt.practiceOptions # questionOrder / choiceOrder
pt.currentSession  # 진행 중 풀이 세션 스냅샷 (문제 키·선지 순서·답안)
pt.mockExamConfig  # 모의시험 설정
pt.mockExamSession # 진행 중 모의시험 세션 스냅샷 (문제 키·선지 순서·답안)
passture.questionMapExpanded # 풀이 화면 문제 번호 지도 펼침 여부
passture.quiz.scrollY # 풀이 화면 스크롤 위치 복원
```

오답 기록은 풀이 세션에서 문제를 처음 채점(정답 확인 또는 채점하기)할 때 틀리면 `wrongCount`를 1 올리고 `lastWrongAt`을 갱신한다. 같은 세션에서 다시 확인하거나 나중에 맞혀도 기록을 줄이거나 지우지 않는다.

`pt.bookmarks` 예시:

```json
["operating-systems:past-exams-2019:e19-01", "algorithms:workbook:b03-07"]
```

`pt.wrongAnswers` 예시:

```json
{
  "operating-systems:past-exams-2019:e19-01": {
    "wrongCount": 2,
    "lastWrongAt": "2026-05-06T12:30:00.000Z"
  }
}
```

`pt.currentSession`, `pt.mockExamSession`은 문제 키와 선지 순서만 담은 version 2 스냅샷이다(§2). 복합 키 형식과 식별자 규칙은 [data-schema.md §4](./data-schema.md) 참고.

## 4. 백업: 내보내기

현재 브라우저의 사용자 데이터를 JSON 파일 하나로 내려받는다. 파일명은 `passture-user-data-YYYYMMDD-HHMMSS.json`(UTC 기준)이다.

```json
{
  "app": "passture",
  "version": 1,
  "exportedAt": "2026-05-06T12:50:00.000Z",
  "bookmarks": ["operating-systems:past-exams-2019:e19-01"],
  "wrongAnswers": {
    "algorithms:workbook:b03-07": {
      "wrongCount": 2,
      "lastWrongAt": "2026-05-06T12:40:00.000Z"
    }
  }
}
```

## 5. 백업: 가져오기

선택한 JSON 파일을 검증한 뒤 `localStorage`에 반영한다. 덮어쓰기는 기존 데이터를 교체하고, 병합은 북마크를 중복 제거해 합치며 같은 오답 키는 `wrongCount` 큰 값·`lastWrongAt` 최근 값을 쓴다. 알 수 없는 문제 키는 삭제하지 않고 보존한다.

## 6. 백업: 검증 규칙

가져오기 파일 조건(실패하면 `localStorage`를 바꾸지 않고 오류를 표시한다):

- 최상위 `app` 값이 `"passture"`
- `version`이 지원 가능한 버전
- `exportedAt`이 비어 있지 않은 문자열
- `bookmarks`가 문자열 배열
- `wrongAnswers`가 객체이고, 각 항목의 `wrongCount`는 0 이상의 숫자, `lastWrongAt`은 비어 있지 않은 문자열
- 문제 키는 `{subjectId}:{sourceId}:{questionId}` 형식 (`questionId`는 `e19-01`처럼 영문 소문자 1자 + 두 자리 + `-` + 두 자리)
